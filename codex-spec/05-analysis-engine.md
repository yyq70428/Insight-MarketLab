# 05 — 分析與 Agent 規格

## ZigZag 與轉折點

- 輸入為時間升冪的開高低收資料。
- 轉折門檻需同時參考價格百分比、ATR 與局部極值。
- 相鄰轉折必須高低交替；同方向出現更極端價格時更新原轉折，不得新增重複方向。
- 最後一個尚未確認轉折可用於形成中型態，但必須明確標示未完成。

## 諧波型態

- 以 X、A、B、C、D 五點評估 Gartley、Bat、Butterfly、Crab、Deep Crab、Shark、Cypher 與 ABCD 等型態。
- 每種型態具有 AB 相對 XA、BC 相對 AB、CD 相對 BC 與 XD 相對 XA 的許可比例。
- 完成型態使用實際 D 點；形成中型態使用預估 D 區間與潛在反轉區。
- 評分綜合比例誤差、形態方向、完成狀態與時間新鮮度。
- 最多回傳 8 個結果，依評分與時間排序。
- 目標價以 D 點與 A 到 D 波幅的 Fibonacci 回檔或延伸計算。

## 支撐壓力

- 候選點來自局部高低點、轉折點與成交量加權價格。
- 價格相近候選點依 ATR 與價格比例聚類為區間。
- 每個區間包含下限、上限、中點、觸及次數、強度與最近時間。
- 低於現價為支撐，高於現價為壓力；現價落在區間內時依中點判定。
- 最多回傳 6 個區間，優先顯示靠近現價且強度高的區間。

## 技術面 Agent

- 最少需要 80 根錨點前 K 線才能進入持久化 Flow。
- 獨立評估諧波型態、支撐壓力、MACD 與 RSI。
- 四項權重預設各 25，允許 0 至 100，合成前正規化。
- MACD 允許柱狀圖與波形兩種模式，並允許快慢期、訊號期、回看長度、斜率權重與位置權重。
- RSI 允許均值回歸與趨勢兩種模式，並允許週期與敏感度。
- 諧波可設最低評分、形成中折減與時間半衰期。
- 支撐壓力可使用距離或強度評分，並設定 ATR 空間、價格空間與距離尺度。
- 報告包含多空百分比、建議、預期買入價、賣出價、下檔價、漲跌幅、目標根數、預期時間與四個元件理由。

## 新聞面 Agent

- 標的與大盤必須各有至少一篇已驗證文章，否則證據不足。
- 模型最多輸出 6 筆 findings，每筆必須引用已提供的唯一來源識別值，並保持 stock 或 market 類型一致。
- 無效、重複或類型不符的引用必須忽略並記入限制，不得參與評分。
- 每筆 finding 包含方向分數、相關度與具體理由。
- 標的分數預設權重 60％，大盤分數預設 40％。
- 報告包含多空百分比、方向分數、資料覆蓋度、摘要、限制、逐篇判斷、來源、搜尋輪次、擷取耗時與模型耗時。

## 決策與紙上驗證

- 決策 Agent 只能讀取同一 session 的技術與新聞報告摘要，不得讀取文章全文或未來 K 線。
- 輸出為 BUY、SELL 或 HOLD，並包含信心、技術理由、新聞理由、來源識別值與風險。
- 引用不存在的新聞識別值時必須阻止決策。
- 完成決策後才可取得錨點後 K 線。入場價為第一根未來 K 線開盤價。
- BUY 與 SELL 依目標價、停損價與最長持有根數離場。同一根 K 線同時觸及目標與停損時，保守視為先停損。
- HOLD 在觀察期內測量相對入場開盤價的最大上漲與最大下跌。兩者都不超過觀望門檻才為預測成功。
- 買賣淨報酬需扣除往返成本點數；HOLD 的紙上報酬為零。

## 自適應與版本驗證

- 自適應 Agent 在決策與驗證完成後執行。
- 未走完觀察期時只儲存報告，不使用不完整結果學習。
- 技術候選使用時間順序的訓練、驗證與一次性測試區段。
- 新聞、技術與決策候選都必須在後續 session 以影子角色同時測試。
- 影子樣本必須在候選生效時間之後，且結果視窗不重疊。
- 預設至少 8 個影子 session，平均淨報酬改善至少 0.1 個百分點，且近似 95％下界高於零，才能通過。
- 新聞候選還必須通過忠實度門檻；未啟用或無評審結果時不可自動提升新聞版本。
- 通過時發布新版本，不得篡改原候選；回滾也必須發布新版本並保留事件。

## 完整 Flow 與區間回測

- 單次 Flow 中，技術與新聞並行，兩者完成後執行決策，最後執行自適應。
- 區間回測將日期內每個實際交易日當作一個錨點，每輪固定日線。
- 每輪必須完整完成才建立下一輪，並以 previousSessionId 串接。
- 第一輪套用使用者當前參數；後續輪次使用當時已生效的版本，只固定批次的最長持有期與 HOLD 門檻。
- 任何由前一輪未來結果產生的候選，其生效時間必須晚於該結果，不得影響早於該時間的後續錨點。
