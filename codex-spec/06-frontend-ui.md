# 06 — 前端介面規格

## 視覺方向

- 主頁外觀必須以 HomePageUI 為基準，維持專業交易工作台的高密度深色介面。
- 背景採近黑藍灰，面板略亮，邊框低對比；主操作為鮮藍色，看漲為青綠，看跌為紅色，警示為橘色，自適應為紫色。
- 主圖表是視覺主體，右側 Agent 側欄不得壓縮圖表到無法閱讀。
- 所有功能按鈕必須可操作，不得使用無行為的裝飾按鈕。

## 頂欄

依序包含 MarketLab 品牌、標的搜尋、週期切換、歷史錨點、諧波型態、支撐壓力、ZigZag、RSI、MACD 開關、最新價與漲跌、Agent 後台、掃描器、個股資訊、量化回測與側欄開關。

錨點控制使用日期選擇器，可清除回到即時模式。錨點存在時，K 線、報價摘要、RSI、MACD、疊圖與 Agent 一律只顯示錨點當日及以前資料。

## 主圖表與副圖

- 主圖顯示 K 線、成交量、圖例、開高低收與載入狀態。
- 諧波疊圖顯示 XABCD 連線、標籤、潛在反轉區、目標價與形成中投影。
- 支撐壓力以區間帶顯示，同時顯示中點、類型、價格與強度。
- RSI 與 MACD 為主圖下方獨立副圖，高度明顯小於主圖，可拖曳調整並可關閉。
- 左側工具列提供十字游標、趨勢線、水平線與清除畫線。
- 紙上驗證播放時，主圖逐根向後新增 K 線，顯示進場、出場與報酬標記，並可回到錨點。

## Agent 側欄

側欄桌面寬度約佔視口 44％，上限約 680 像素，下限約 520 像素。中型畫面縮至約 430 像素，行動畫面改為右側全高抽屜。

### 區間序列回測

位於側欄最上方，包含開始日、結束日、1 至 7 天最長持有、HOLD 成功波動門檻與執行按鈕。

執行後顯示進度條、當前錨點、完成輪數、技術、新聞、決策、自適應的當前狀態、預測成功數、成功率，以及每輪的錨點、行動、信心與結果。重新載入後必須恢復最近批次的輪詢。

### 單次 Flow

- 工具列包含只執行第一層與一鍵執行完整 Flow 兩個按鈕。
- 技術與新聞並列顯示，完成任一階段就立即渲染該報告，不得等全部 Flow 結束。
- 技術面板提供諧波、支撐壓力、MACD 與 RSI 權重滑桿、儲存與執行。
- 新聞面板提供回看天數、搜尋輪數、自動辨識標的名稱、執行、多空分數、耗時、來源與審計。
- 決策面板提供技術與新聞權重、最低決策信心、執行、決策理由、引用、驗證結果與播放狀態。
- 自適應面板顯示新聞品質、建議、候選差異、影子驗證與版本政策。
- 階段狀態使用等待、執行中、完成與失敗，每個階段只在首次完成時渲染一次。

## 其他側欄內容

依序顯示自選清單、諧波型態卡、支撐壓力卡、公司資料與相關新聞。自選清單在 PostgreSQL 不可用時可降級為瀏覽器本地儲存。

## 搜尋

搜尋使用可關閉的模態對話框，支援滑鼠、觸控、鍵盤方向鍵、Enter、Escape 與斜線快捷鍵。搜尋結果必須顯示代號、名稱、交易所與類型，使用者必須從清單選取。

## 後台頁

- 後台固定提供總覽、輪次、策略參數、版本與回滾、稽核事件五個頁籤，並保留跨頁籤的標的範圍選擇。
- 總覽顯示 session 狀態統計、線上交易輪次、前後半平均淨報酬、差值、待驗證候選、建立新輪次表單、累積平均淨報酬曲線、標的範圍與最近策略事件。
- 輪次表顯示錨點、標的、狀態、技術與新聞多空分數、文章數、忠實度、動作、淨報酬、參數變更與自適應結論。
- 策略參數頁按 Agent 分區顯示目前生效規則、版本識別、數值範圍與假設說明。人工儲存必須建立不可覆寫的新版本。
- 版本與回滾頁顯示時間、Agent、狀態、假設、與上一版差異、驗證狀態及回滾操作，並處理 revision 衝突。
- 稽核事件頁顯示時間、範圍、Agent、動作、session 識別與版本識別，確保策略提案、設定、採用與回滾皆可追溯。
- session 詳情顯示四個 Agent 的 champion 與 shadow run、輸入參數、報告、錯誤、事件與版本差異。

## 掃描器、個股與量化頁

- 掃描器以卡片顯示型態，提供方向、完成狀態、市場與產業篩選，並逐步顯示背景掃描進度。
- 個股頁保留主頁圖表風格，並併列公司資料、台灣新聞與國際新聞。
- 量化頁提供單標的即時回測輸入、進度、策略卡、滾動驗證與買入持有比較，並顯示離線研究快照。

## 無障礙與響應式

- 互動元件必須有名稱、鍵盤焦點、停用狀態與足夠點擊區。
- 報告與進度區域使用可讀取的即時更新語意。
- 實用文字不得被截斷或重疊，頁面在行動畫面不得產生非預期水平捲動。
- 中型畫面將第一層雙欄改為單欄；行動畫面以抽屜顯示側欄。
